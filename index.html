Research

Systematic Equity Research Framework

Twelve signal families, thirty-eight strategies, twenty-one years of data — and a calibration procedure showing that none of them beat random noise routed through the same pipeline.

0.036IC required to break even
0.012achievable on free data
0 / 38clearing a calibrated null
2.75t-stat produced by noise

A research harness for cross-sectional equity signals: point-in-time ingestion from SEC DERA and EDGAR, a backtest engine tracking true holdings drift, Fama-French and Ferson-Schadt attribution, and a null-floor control that measures what a zero-information strategy scores in the same pipeline. That control invalidated four of my own earlier conclusions, which is documented rather than quietly fixed.

A Measured Ceiling → The research writeup — what was tested, what failed, and the arithmetic explaining why. What Does Nothing Score? → On calibrating significance against your own pipeline rather than against convention.

Bender

A local-first AI engineering workspace — CLI, web dashboard and desktop app on one backend — built to work through agent architecture properly rather than read about it.

8role runtimes, one shared base
3 → 1interfaces on one backend
56test files
CIeval suites gate the build

Work is decomposed across eight specialised runtimes — analyzer, architect, planner, implementer, reviewer and others — each with its own prompts, tools and skill defaults, rather than one thread accumulating everything. Skills and MCP servers attach as capability per role. The part most agent tooling skips is the eval subsystem: a runner, scorer and aggregator wired to Promptfoo, so a prompt change that scores worse can fail a build. Exploratory and dormant.
